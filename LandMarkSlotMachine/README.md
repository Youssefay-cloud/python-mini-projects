# Arabic Landmark Slot Machine

A small command-line slot machine game built with Python. Spin three landmark symbols and try to match all three within three attempts.

## Requirements

- Python 3.8 or newer

The project uses only Python's standard library, so no extra packages are required.

## Setup and Run

From the `LandMarkSlotMachine` directory, create a virtual environment:

### Linux and macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### Windows

```powershell
py -m venv venv
venv\Scripts\Activate.ps1
```

Run the game:

```bash
python app.py
```

Press Enter when prompted to spin. You have three attempts to match the same landmark three times.

When you are finished, deactivate the virtual environment:

```bash
deactivate
```
